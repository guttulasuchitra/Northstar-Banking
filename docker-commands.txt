docker run vs docker start
- docker run — image nunchi new container create chesi start chesthundi.
- docker start eureka-server — already-created stopped container ni start chesthundi.
- docker stop eureka-server — running container stop chesthundi.
- docker rm eureka-server — stopped container remove chesthundi.
- docker rm -f eureka-server — running or stopped container ni force ga remove chesthundi.
